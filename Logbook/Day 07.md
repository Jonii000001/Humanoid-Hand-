Day 7-8: Index finger CAD

• Today I designed the middle part of the index finger. It took me a really long time, because I didn't use even dimensions, like 5, 6.5, 11.25; I took odd measurements, so I will have to make the part for the second time. The aesthetic and structural design was greatly improved, and what really impressed me was that I could do such a difficult part like this, for the first time.

• I used the exact measurements for the ball bearing housing so that the real MR84ZZ would fit in perfectly. I also want to create a press-fit mechanism.

• Future: I want to create the part for the second, but this time I want to use strict parametric modelling measurements, so that in the future I can easily correct things like the size and so on.
