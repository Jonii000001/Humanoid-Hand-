## AS4048 PCB designing

Today was a really stressful day.

I was really frustrated, because of this PCB layout! I wanted to get the measurements precise so it fits perfectly inside the finger part (very tiny, I has to be tinier than 14x14mm, that's the maximum of size). The board is really tiny—just 12mm x 6.75mm (I will need a microscope and a hot air soldering iron to solder all the components on the PCB)

I used an AS5048A chip with two capacitors (10µF and 100nF), using the SPI interface to read the 14-bit angle data.

I really hope it works, but I'll find out once the hand is assembled.

I think I finally managed it, but because of the hard work, which I had done and the much energy, which robbed me this PCB layout. I'm going to work on it again tomorrow to improve the copper pads and wire connections.

Tomorrow, I'll also want to import the PCB into CAD and look, if it fit perfectly at the joint.

The only problem, which I have it to figure out the mechanical routing to let the cables run straight down, because I want to avoid any mechanical resistance. I'm also currently thinking about, if I should design holes directly into or do it by myself.

I'll post all the documents once it's finished, and I'll probably get them printed via JLCPCB.
