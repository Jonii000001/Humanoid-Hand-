## Distance adding to the bearing mounting and PCB changed to a circle

Today was a really productive day.
I did a lot of things, first I designed a small ring like a distance ring, so I don't have to use a distance disc at the magnet hole (the distance ring is 0.5mm big).

Because I didn't mind that so early, I have to use a distance, so the ball bearing doesn't have resistance at the finger part. I had to change the size of the finger part, because the distance ring with 1mm was too long, so I had to shrink it a bit.

Puhhhh, that was so much work, I crashed the complete finger part, but I luckily had saved it on a memory stick. Furthermore, I also had to redesign the base part of the finger because the width was a bit too small, and I also changed the system because of the diametrically magnetized magnet (the orange part in the screenshot should be the magnet).

In addition, I also tried adding some extensions in CAD to make it a bit better.

At the end, I thought about the PCB and corrected it to a circle and added two holes for a screw or a holder stick, because I'll place it outside of the joint, so it doesn't bother inside, and I can put the cables outside along the base of the humanoid hand.
