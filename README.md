# Humanoid-Hand — Advanced Engineering Logbook

This repository is organized to keep the public view short, while preserving every original daily entry and every image (nothing deleted).

What I changed
- Archived the original, full journal (exact text + all image links) to /logbook/Full-Journal.md so every memory is preserved.

How to add a new daily entry (recommended)
1. Create a file named logbook/Day-XXX-YYYY-MM-DD.md (copy from /logbook/Daily-Template.md).
2. Fill the sections (TL;DR, Objective, What I did, Results, Technical notes, Feelings, Next steps, Images).
3. Commit and push the new file.

Files you will find here
- /logbook/Full-Journal.md — the full original README content (archived; unchanged text and image links).
- /logbook/Daily-Template.md — a short template to copy each day.
